# AGENTS.md

## What this repo is

Jekyll static site (GitHub Pages) counting down to FPGA conference deadlines. Forked from `aideadlines`. Live at `https://itsruthwik.github.io/conf-deadlines/`. Primary branch: `gh-pages`.

## Key commands

```bash
# Build the site
bundle exec jekyll build --future

# Validate HTML output
bundle exec htmlproofer ./_site --only-4xx --check-favicon --check-html --url-ignore "/#.*/" --http-status-ignore "400,441" --url-swap "^/conf-deadlines/:/" --empty-alt-ignore
```

`--future` is required in the build so upcoming deadlines are included in output.

`--url-swap` strips the `baseurl` prefix so htmlproofer can resolve `/conf-deadlines/...` internal links against the local `_site`. `--empty-alt-ignore` accepts the decorative `alt=""` icons on the conference detail page. External checks may still report a 404 for `github.com/itsruthwik/conf-deadlines` if the repo is private.

## Data model

All conference data lives in `_data/conferences.yml`. Each entry requires: `title`, `year`, `id`, `link`, `deadline`, `timezone`, `date`, `place`, `sub`.

- `id` format: lowercase title + last 2 digits of year (e.g. `isca26`, `asplos26`)
- `deadline` format: `YYYY-MM-DD HH:MM:SS` or `TBA`
- `timezone`: moment-timezone string (e.g. `America/New_York`, `UTC-12`) or `TBA`
- `sub`: list of subject tags from `_data/types.yml` (currently `ARCH`, `CAD`, `APP`)
- Optional: `abstract_deadline`, `note`, `hindex`, `paperslink`, `full_name`, `start`, `end`

## Python utility

`utils/process.py` sorts and cleans conference data. Run from inside `utils/` dir (reads `../_data/conferences.yml`). Outputs `sorted_data.yml` — manually copy back after screening.

## Conference refresh workflow

`workflow/` holds a hybrid deterministic + agentic pipeline to update `_data/conferences.yml` from live CFP pages (see `workflow/README.md`). Run it via opencode:

```bash
bash workflow/refresh.sh            # all tracked conferences
bash workflow/refresh.sh fccm       # single conference
```

The deterministic scripts (`fetch_cfp.py`, `validate.py`, `normalize.py`, `merge.py`) can also be run directly. `workflow/cache/` and `workflow/staged/` are gitignored.

## Architecture notes

- Jekyll 3.9.2 with `github-pages` gem (Ruby 2.4)
- Per-conference detail pages generated by `_plugins/data_page_generator.rb` using `_layouts/calendar.ics`
- Client-side JS in `_includes/` handles timezone conversion, filtering, countdown timers
- `_data/types.yml` defines subject filter options (name, sub code, color)
- CI: Travis CI on `gh-pages` branch
- `.gitignore` excludes `scripts/`, `conductor/`, `set_env.sh` — these are local-only
